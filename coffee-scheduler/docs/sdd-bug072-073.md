# BUG-072 and BUG-073 acceptance criteria

**F11.ac22**: Per-assignment legality reuses an immutable compliance snapshot only within one
adapter closure, keyed by tenant, employer, and employee; filtering to per-assignment rules occurs
once for each cached snapshot and candidate verdicts remain unchanged.

**F11.ac23**: Weekly maximum hours are enforced independently for every touched ISO week, including
partial weeks, without pro-rating; a multi-week window is not capped by one week's maximum.

**F11.ac24**: Weekly minimum hours apply only to ISO weeks fully contained in the target window;
each omitted partial-week minimum is recorded on `SchedulingModel.skipped_minimums`.

**F11.ac25**: A zero weekly minimum emits neither a minimum constraint nor a skipped-minimum record.

**F11.ac26**: Contradictory employee weekly bounds fail model construction with a typed error naming
the employee.
